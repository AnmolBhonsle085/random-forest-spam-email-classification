Text Classification Using Random Forest

📌 Project Overview

This project demonstrates text classification using Machine Learning with Python and the Random Forest algorithm. It uses CountVectorizer to convert text into numerical features and classifies new text inputs into predefined categories.

🎯 Objectives

- Understand supervised machine learning for text classification.
- Convert text data into numerical features.
- Train a Random Forest classification model.
- Predict categories for new text inputs.

🛠️ Technologies Used

- Programming Language: Python
- Machine Learning Library: Scikit-learn
- Feature Extraction: CountVectorizer
- Algorithm: Random Forest Classifier

⚙️ How It Works

1. Data Preparation: Uses 8 labeled text samples belonging to two categories: Spam and Not Spam.
2. Feature Extraction: CountVectorizer converts text into numerical word-count features.
3. Model Training: Random Forest learns patterns from the labeled training data.
4. Prediction: The trained model predicts a category for a new text input.

📊 Project Metrics

- Training Samples: 8
- Classification Categories: 2
- Decision Trees: 100
- Model Type: Supervised Learning

Note: This is a beginner-level demonstration using a very small dataset. Model accuracy has not been measured, so the results should not be considered reliable for real-world classification.
